# 🎓 AttendEase

A web-based attendance system designed for higher education institutions, featuring automated QR code validation, geo-fencing checks, and role-based management dashboards.

---

### ✨ Technologies

* **Backend:** PHP (PDO), MySQL
* **Frontend:** HTML5, Modern CSS, JavaScript
* **Authentication:** Role-Based Access Control (RBAC), Session Management
* **Features:** QR Code Generation, Geolocation API

---

### 🚀 Features

* **Dynamic QR Code Generation:** Real-time generation of temporary session QR codes for instant check-ins.
* **Location Verification:** Geo-fencing checks to ensure students mark attendance strictly within class boundaries.
* **Role-Based Portals:** Dedicated management interfaces for Administrators, Lecturers, and Students.
* **Automated Reporting:** Real-time tracking and statistical summaries for attendance records.

---

### 📍 The Process

Traditional attendance tracking in lecture halls suffers from proxy signing, manual data entry errors, and lost time. I built **AttendEase** to streamline classroom workflows into a seamless digital process. By pairing time-sensitive QR codes with geolocation validation, the system minimizes attendance fraud while providing clean, actionable reporting for university staff.
